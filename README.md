# 📚 Book Management System

A web system for managing books, developed with Python, Flask and a Firebird database.

This project was created as a backend activity during the Systems Development course at SENAI and is still being improved as new concepts are studied.

## ✨ Features

- Book registration
- Book listing
- Edit book information
- Delete books
- Firebird database integration
- User registration
- Login system in development
